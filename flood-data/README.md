# Flood Research Data Sources

Public source-provider catalog for flood, housing and resilience research. Open index.html or serve this directory as static files. No build step or backend is required. Search and topic filters run locally in the browser.

The guide links to original providers; it does not redistribute analytical data. Access, licenses and restrictions remain with providers. Provider guidance was reviewed 28 October 2026; exact downloads are not guaranteed.

CECREH logo source: https://www.depts.ttu.edu/cecreh/images/CECREH-Logo.png

## Public-release changes
- Replaced the promotional slogan with the descriptive page title.

- Retained the source directory, research candidates, filtering, design, provider links and responsible-reuse guidance.
