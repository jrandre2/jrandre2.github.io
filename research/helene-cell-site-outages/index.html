Helene cell site outages

Reproduction materials for Predicting Peak Cell Site Outages and Tracking Recovery During Hurricane Helene in Western North Carolina, by Jesse R. Andrews.

  • Download the reproduction package (ZIP)
  • Browse the code, derived data, and run instructions on GitHub

The package reruns the main benchmark comparisons from frozen derived inputs and checks the figure data and supplementary score extracts. It does not recreate the raw data extraction, the full geographic processing, or every exploratory model fit. The source inventory links to the public upstream records.
